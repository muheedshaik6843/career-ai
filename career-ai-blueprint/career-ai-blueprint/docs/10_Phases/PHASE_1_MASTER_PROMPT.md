# Phase 1 – Foundation

## Goal
Build the project foundation for an AI Career Assistant.

### Stack
- Next.js (TypeScript, App Router)
- Tailwind CSS + shadcn/ui
- FastAPI
- PostgreSQL
- SQLAlchemy + Alembic
- JWT Authentication
- Docker + docker-compose
- GitHub Actions
- Environment variable management

### Deliverables
- Monorepo structure
- Authentication (email/password)
- Google OAuth (optional)
- User profile
- Responsive dashboard shell
- Dark/light mode
- Logging
- Swagger/OpenAPI
- README
- Initial deployment configuration

### Definition of Done
Application runs locally with frontend, backend and database connected.
